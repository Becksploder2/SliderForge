# SliderForge

## Dynamic team backgrounds — test prototype

Open [index.html](index.html) locally in a browser to test the dynamic team watermark UI. It works without an internet connection after downloading.

Features:
- Different HOME and AWAY team selection with a background-source toggle.
- Automatic watermark updates and team-color accents.
- Adjustable opacity (5–40%) and an on/off switch.
- Import a custom TeamBuilder team name, color, and PNG/JPEG/WebP image (up to 1.5 MB).
- Browser-local persistence of settings and custom teams.
- Demo team abbreviations instead of unlicensed official logos.

**Important:** This repository currently does not contain the actual SliderForge slider application source. This HTML file is a standalone functional UI test, not an integration into the Windows application. Actual gameplay-slider controls, full team catalogs, Windows installers, and official logo assets are not included. Once the real application source is committed, the background component can be integrated without replacing its existing modes or sliders.
